Open, down to the source.

The complete code is public. The assistant runs locally, with your account information and private keys kept in your Chrome profile.

How the protection works

The extension generates a random encryption key. Device verification uses WebAuthn PRF to protect that key. Fingerprint and face data stay inside your device’s security system. Passkey private keys sign Duo’s requests locally; Duo registers the corresponding public key.

A few useful details

Good to know.

Where does it work?

Start from my.UChicago, its student portal, the Courses homepage, or any application that opens a recognized UChicago Okta sign-in page. The assistant follows the approved flow across Okta and compatible Duo pages, including sign-ins for third-party services.

What happens during the first setup?

After you save your account, the assistant guides you to Duo device management. Complete Duo’s identity check using an existing verification method, then confirm Add a passkey. Once Duo registers the new security key, automatic verification is ready.

Can I keep using my usual Duo method?

Yes. Your existing Duo methods stay available. A saved, usable passkey activates automatic verification for the account; your other methods remain ready for identity checks and account recovery.

How do I update the extension?

Download the latest source into the same project folder, open Chrome’s extensions page, and choose Reload. This keeps your saved account and passkeys in the existing installation.
