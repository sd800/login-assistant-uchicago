[English](README.md)

「UChicago 登录助手」是一款供个人使用的 Chrome 插件，帮助您更加轻松快捷地登录您的芝加哥大学账号。

UChicago 的各项服务通过 Okta 和 Duo 完成登录，因此打开 my.UChicago、Canvas 和其他学校服务时，通常需要经过账号填写、页面跳转、验证方式选择和 Duo 验证等多个步骤。

本插件将这些步骤整合为一套清晰连贯的流程。您每次确认登录后，插件会完成可识别的账号与 Duo 操作，让您更快进入需要使用的服务。

- 支持 my.UChicago、Canvas，以及使用芝加哥大学账号登录的第三方应用。
- 完成账号和通行密钥设置后，在您每次授权登录时自动完成学校账号登录流程。
- 使用符合行业标准的加密方式，将账号信息和通行密钥安全地存储在您的设备上。
- 提供英文和简体中文界面，并支持根据系统自动切换浅色和深色模式。
- 完全开源，完整的源代码和技术实现均在 GitHub 上公开。

## 安装

需要桌面版 Google Chrome 122 或以上。插件可直接从项目内的 `extension/` 文件夹加载运行。

1. 下载或克隆本仓库，也可以解压项目 ZIP，将文件放在固定目录中。
2. 打开 `chrome://extensions`，启用**开发者模式**。
3. 点击**加载已解压的扩展程序**，选择项目内的 **extension** 文件夹。
4. 首次安装后会自动打开**设置**。以后可从 Chrome 的扩展程序菜单打开 **UChicago Login Assistant**，进入**设置**。

更新时，在原目录替换项目文件，到 `chrome://extensions` 重新加载插件，再刷新已打开的登录页面，即可保留现有安装中的账号密码和通行密钥。卸载插件会删除插件保存在本地的数据。

## 初次设置

请在**设置**中完成以下步骤。账号信息和通行密钥私钥均受本地加密保护，仅用于您明确授权的登录。

### 保护已保存的数据

打开**登录授权验证**，点击**使用设备验证**。Chrome 会调用 Touch ID、Windows Hello 或设备提供的验证方式。设置完成后，页面会显示绿色对勾。

插件会随机生成本地加密密钥，并使用符合行业标准的 AES-256-GCM 加密已保存的账号信息和通行密钥私钥。WebAuthn PRF 将这把加密密钥的保护与本插件的设备凭据绑定。指纹和面容数据始终由设备的安全系统保管。

### 保存账号

打开**账号**，填写 **CNetID 或 UCMEDID** 和**密码**，点击**保存**。请在插件中填写这些信息。账号信息加密保存在本设备上，仅会在您明确确认的登录中使用。

### 添加 Duo 通行密钥

保存账号后，请在提示中确认添加通行密钥，启用账号一键登录。您也可以到**设置 → Duo 与通行密钥**点击**添加通行密钥**。插件会打开新的学生登录页面，并引导完成注册流程。

1. 插件打开 Duo 的验证方式菜单，选择 **Manage devices**。请完成 Duo 显示的身份验证，随后插件会自动继续。
2. 进入设备管理后，插件会依次选择 **Add a device → Security key → Continue**。在插件的**添加通行密钥**窗口中，点击**继续**。
3. Duo 的设备列表出现新安全密钥后，插件会选择 **Back to login**，再选择 **Security Key**。Duo 完成注册后，这枚密钥即可用于自动验证。

插件会在本设备上生成专属的通行密钥密钥对。私钥由 AES-256-GCM 加密保护，对应的公钥则注册到 Duo。登录获得授权后，私钥会在本地为 Duo 的验证请求生成签名，并始终保留在本设备上。

Chrome 的网站访问权限使插件能够在您已授权的登录流程中处理可识别的 Duo 页面。请保留其他 Duo 验证方式，用于账号恢复和设备管理。

## 日常登录

打开您要使用的服务，按插件提示确认登录。以下入口均受支持：

| 从哪里开始 | 确认后插件会做什么 |
| --- | --- |
| [my.UChicago](https://my.uchicago.edu/) | 跳过门户页，直接进入学生登录；支持 HTTP 和 HTTPS |
| [my.UChicago 门户](https://portal.uchicago.edu/ais/) | 不等待门户页加载，直接进入学生登录 |
| [Courses 首页](https://courses.uchicago.edu/) | 进入 Canvas 登录地址 `https://canvas.uchicago.edu/login/1` |
| UChicago Okta 登录页，包括 `https://uchicago.okta.com/app/*` | 自动填写账号密码，完成可识别的登录步骤 |

插件会询问：

> 使用已保存的账号登录 UChicago？

点击**确认**继续，点击**取消**则停止。从 my.UChicago 开始时，提示会在当前标签页打开；取消后进入普通门户页。焦点位于页面或确认按钮时，可按 **Enter** 或**空格键**确认，按 **Esc** 取消。输入框等控件中的按键功能不变。

确认后，请按设备提示完成验证。这次授权只适用于当前标签页中的登录，最长五分钟，并覆盖期间受支持的页面跳转。如果当前账号有可用的通行密钥，插件会在 Duo 中选择 **Security Key**，并在同一次授权中使用该密钥。Duo 会管理受信任浏览器状态，并在需要时显示身份验证页面；请按 Duo 页面提示完成验证。

您可以切换到其他标签页，插件会在已授权的标签页继续处理支持的登录步骤。Duo 验证完成后，出现 **Is this your device?** 页面时，插件会选择 **Yes, this is my device**。学校登录状态仍然有效时，系统会直接返回应用。

请从您要使用的应用开始。插件支持不同域名下的学校服务和第三方应用，并会识别它们打开的 UChicago Okta 登录页面。每次新的登录都会单独请您确认。

### 控制窗口与已保存的通行密钥

| 控件 | 用途 |
| --- | --- |
| 电源图标 | 启用或停用插件 |
| 圆形箭头 | 取消或中断后，在当前受支持页面重新询问是否登录 |
| 设置图标 | 管理账号、通行密钥、登录授权验证、语言和本地数据 |

控制窗口的卡片图标表示账号密码已保存；钥匙图标表示本地已有受保护的通行密钥，Duo 设备管理页面会显示该密钥的注册状态。在**设置**顶部切换语言后，插件窗口会立即更新，刷新页面也会保留选择。明暗外观由系统设置决定。

**Duo 与通行密钥**会显示当前验证方式。账号已有可用密钥时，插件使用**自动验证**；**手动验证**则让您使用熟悉的 Duo 验证方式，添加通行密钥后即可启用自动验证。已保存的密钥会显示所属账号、添加时间和删除按钮。设置入口会根据当前账号状态显示在适合的位置。

Duo 明确拒绝的密钥会标为**已失效**，并从自动验证中暂时移出。插件会引导您前往 Duo 设备管理添加替代密钥。当前登录可继续使用您选择的 Duo 验证方式，下次确认登录时会接续替换流程。密钥状态以 Duo 的明确反馈为准；超时、取消或未匹配的请求会保留当前状态。所有本地密钥始终由您管理，直到您手动删除或清除本地数据。

遇到需要其他认证器功能的请求时，请选择**改用其他通行密钥**或其他 Duo 验证方式。插件内置的认证器负责本地 ES256 通行密钥和兼容的 Duo WebAuthn 请求，Chrome 则负责特定服务提供商的功能。Duo 会按照自身的凭据策略完成注册和验证。

## 隐私与安全

插件使用浏览器内置的 Web Crypto API 和 AES-256-GCM，将已保存的用户名、密码及通行密钥私钥加密存放在当前 Chrome 配置文件中。插件会随机生成加密密钥，并通过 WebAuthn PRF 与设备验证共同保护这把密钥。Touch ID、Windows Hello 或相应的系统登录验证均由设备安全系统完成，指纹与面容数据始终保留在系统中。

- 每次登录都需要您先确认。授权只适用于当前标签页和账号，最长五分钟。使用已保存的信息前，插件会核对当前页面、HTTPS 来源及本次登录流程。
- 账号信息只会用于可识别的 UChicago Okta 登录页。通行密钥在本地生成：Duo 注册公钥，私钥保留在您的设备上，并在已授权的 Duo 登录流程中为兼容请求签名。
- 所有处理均在本设备完成。插件独立运行，不接入使用情况统计、广告、云同步或开发者数据服务器。确认添加通行密钥后，插件会清理指定学校登录网站的 Cookie，以便开始新的登录，并立即丢弃 Cookie 内容。
- 最近活动只包含状态和时间，最多保留过去 24 小时内的 20 条，过期记录会自动删除。

| 权限或网站访问范围 | 用途 |
| --- | --- |
| `storage` | 保存设置、最近活动和临时登录状态 |
| `scripting` | 管理 Duo 页面适配 |
| `webNavigation` | 跟踪登录跳转，确认请求来自当前标签页和页面 |
| `alarms` | 清理过期请求、授权和活动记录 |
| `declarativeNetRequestWithHostAccess` | 在 my.UChicago 跳转到门户之前显示登录确认页 |
| `cookies` | 添加通行密钥前，准备新的学校账号登录 |
| `*://uchicago.okta.com/*` | 识别并完成支持的学校账号登录步骤 |
| `*://*.duosecurity.com/*` | 确认登录后，处理支持的通行密钥请求 |
| `https://portal.uchicago.edu/*` | 从门户进入学生登录 |
| `https://courses.uchicago.edu/*` | 从 Courses 首页进入 Canvas 登录 |
| `*://*.ais.uchicago.edu/*` | 将 AIS 纳入学生登录的网站访问范围，保留网站原有的服务器跳转 |
| `*://my.uchicago.edu/` | 从 HTTP 或 HTTPS 的 my.UChicago 首页直接进入学生登录，账号填写在可识别的 HTTPS Okta 页面完成 |

可在 Chrome 的**网站访问权限**中管理上述权限。插件会将 Duo 操作与您已确认的标签页、账号和本次登录流程绑定。

### 删除数据

**设置 → 本地数据 → 清除本地数据**会删除保存的账号密码和通行密钥，并重置设置、语言及活动记录。卸载插件或删除对应的 Chrome 配置文件，同样会删除这些数据。

您的学校账号、Duo 注册记录和其他服务保管的通行密钥都会继续保留。Duo 注册记录可在 Duo 设备管理中维护；请同时准备另一种验证方式，以便恢复账号。

## 常见问题

| 问题 | 怎么处理 |
| --- | --- |
| 登录提示尚未显示 | 先保存账号、启用插件，并允许访问相关网站，再刷新入口或真正的 Okta 登录页。账号设置和密码找回页面会保持原有用途。 |
| 取消后继续登录 | 点击控制窗口的圆形箭头，重新发起登录。 |
| 从入口页或 Duo 页面继续 | 检查 Chrome 的网站访问权限，在同一标签页重新登录并确认提示。遇到服务提供商专属步骤时，请使用页面显示的验证方式继续。 |
| Chrome 显示通行密钥服务 | 可用的本地密钥与已确认的登录流程会启用自动验证。重新加载插件并发起一次新的学校账号登录，即可恢复该状态。需要其他认证器处理的请求会先显示服务选择提示。 |
| Duo 显示新的身份验证 | 请完成设备验证，或选择您要使用的 Duo 验证方式。每次确认登录都会获得新的五分钟授权时段。 |

## 开发

需要 Node.js 22 或以上。项目只使用 Node 内置的运行时和测试模块。

```sh
npm run check                  # 静态检查与文档检查
npm test                       # 界面、本地化和主题的精简测试
npm test -- controller policy  # 运行指定测试组
npm run package                # 静态检查与打包
```

完整测试使用 `npm run test:all`。打包会先执行静态检查，再在 `dist/` 中生成源码目录、ZIP 和 SHA-256 校验文件。需要运行完整测试时，请在打包前执行 `npm run test:all`。

可加载的插件位于 `extension/`，使用模拟数据的测试位于 `test/`，检查与打包脚本位于 `scripts/`。`extension/` 根目录保留插件清单；`background/` 存放后台脚本，`pages/` 存放插件页面，`ui/` 存放共用界面文件，`content/` 存放网页适配代码，`core/` 存放登录逻辑，图标和语言文件分别存放在 `icons/` 与 `locales/`。
